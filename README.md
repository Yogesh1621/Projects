## 🔧 Project Overviews

### 1. Terminal & Bash Commands Documentation Guide
*   **Tech Stack:** HTML5, Bash
*   **Concept:** To master file systems and terminal environments, I hand-coded a technical documentation cheat sheet. The interface implements proper text-formatting hierarchies and custom character entity scaling (`&lt;` and `&gt;`) to cleanly render system input strings, dynamic directory switches, and core text-pattern operations (`grep`) safely inside the web browser.

### 2. Typographic Notation Sandbox
*   **Tech Stack:** HTML5
*   **Concept:** A mini-project exploring layout structure, structural horizontal breaks, and scientific inline notations. It utilizes typographic layout elements like `<sub>` and `<sup>` to display chemical formulas ($H_2O$) and physics laws ($E=mc^2$) accurately within native text flows.

### 3. Terminal-Based Nim Variant Logic Game
*   **Tech Stack:** Python 3 (`random` module)
*   **Concept:** A completely independent logic game built to test core algorithmic programming. The script runs a competitive integer subtraction game where a user faces off against a computer-generated opponent. It uses automated control loops, type casting, input validation boundaries, and a state evaluation engine to calculate win/loss triggers when the integer baseline hits zero.
